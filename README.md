# Sistema de Gestión Escolar "EduControl"

## Presentación del Proyecto Académico

Este proyecto fue desarrollado como parte de las actividades prácticas de la materia de Ingeniería de Software. Nace de la necesidad de automatizar y organizar el control de asistencias y notas en escuelas pequeñas que todavía usan papel.

El ***objetivo general*** de esta aplicación es brindar una plataforma en internet que sea muy fácil de usar, permitiendo a los profesores registrar las calificaciones de sus alumnos en pocos minutos y reducir el papeleo diario.

### Principales Funcionalidades
* Registro de alumnos nuevos organizados por curso y año.
* Control diario de asistencia con un solo clic.
* Cálculo automático de los promedios finales de cada estudiante.
* Opción para descargar el reporte de notas listo para imprimir.
